# Quest

A real-world challenge network built around doing things rather than
passively consuming a feed.

Core loop:

Create Quest
→ Accept Quest
→ Attempt
→ Submit Proof
→ Complete
→ Challenge Someone Else

## Product principles

- Real-world action over passive consumption
- Proof over performance
- Progression over follower counts
- Participation over spectatorship
- AI assists the system but is not the product
