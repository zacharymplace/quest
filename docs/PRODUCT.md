# Quest Product Model

## Core objects

### Quest
A challenge someone can accept and perform.

### Attempt
A person's active run at completing a quest.

### Proof
Evidence that an attempt satisfies the quest.

### Completion
A verified finished attempt.

### Challenge
An invitation from one person to another to attempt a quest.

## Initial progression dimensions

- explorer
- cook
- maker
- musician
- creator
- fitness
- social
- wildcard

## Viral loop

completion
→ shareable accomplishment
→ challenge another person
→ new acceptance
→ new completion

## Retention loop

attempt
→ completion
→ reputation/progression
→ better quest recommendations
→ harder or more interesting attempts
